Principais formatações

Negrito / Destaque

Nesta frase, temos um termo em negrito utilizando a tag "b" (não semântica)

Nesta frase, temos um termo em destaque utilizando a tag "strong" (semântica)

Itálico / Ênfase

Nesta frase, temos um termo em itálico utilizando a tag "i" (não semântica)

Nesta frase, temos um termo com ênfase utilizando a tag "em" ("emphasis"; não semântica)

Marcação

Podemos marcar uma palavra ou frase com a tag "mark"

Para alterar a cor da Marcação, usa-se style como parâmetro dentro da tag mark, a tag "style" no "head" do documento, ou ainda um css externo.

Texto grande / pequeno

Nesta frase, temos um termo com letras grandes utilizando a tag "big", que já se tornou obsoleta.

Nesta frase, temos um termo com letras pequenas utilizando a tag "small", que ainda é utilizada.

Texto inserido / deletado

Nesta frase, temos um termo que deve ser lido, mas não considerado.

Nesta frase, temos um termo que foi inserido depois ("preenchimento de lacuna"; semântica)

Ainda existe a tag "u" que também faz o texto aparecer sublinhado, mas já se tornou obsoleta (não semântica)

Texto sobrescrito / subscrito

Para escrever coisas do tipo x2+3, usamos a tag "sup" no carctere desejado.

Para escrever coisas do tipo H2O, usamos a tag "sub" no carctere desejado.
